{% comment %} Interactive PNEC Neighborhood Map (v1, May 2026) Replaces the static lightbox image on /pages/find-your-neighborhood.html with a hover/click-to-explore overlay over the same official PNEC PNG. How it works: - The PNG renders at full width inside a 1376:1844 aspect-ratio box. - A transparent SVG with viewBox="0 0 1376 1844" overlays the image. - JS fetches /assets/data/poway-neighborhoods.json and draws one invisible per neighborhood at its normalized x,y position. - hover/focus/click → side panel slides out with all the details. Why SVG over : scales cleanly, supports CSS hover, focusable for keyboard users, and the polygons can be upgraded to real shapes later without a markup change. Why this doesn't replace the existing Leaflet/OSM `pnec-map` element: this preserves the official PNEC branded map. The Leaflet view stays available on a future "/map?view=osm" toggle for users who want a street-level base. {% endcomment %}
